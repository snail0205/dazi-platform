# 城市「搭子」组局平台 —— 核心接口清单（RESTful v1）

> 配套：《需求文档》v0.9、《数据库 DDL》。版本化前缀：C 端 `/api/v1/**`，运营端 `/admin/v1/**`，支付回调独立前缀（不鉴权）。

---

## 0. 通用约定

### 0.1 基础
- Base URL：`https://api.dazi.example.com`（本地开发 `http://localhost:8080`）
- 请求/响应均 JSON（UTF-8）；回调接口除外（微信支付回调为 XML/`text/plain`）
- 金额字段一律为**整数「分」**；时间为 `yyyy-MM-dd HH:mm:ss`
- 分页：`GET` 用 `page`（从 1 起）+ `pageSize`（默认 10，上限 50）；时间线列表用 `cursor`（取上一页最后一条的 id，`limit<=50`）
- 幂等：`POST /activities/{id}/join`、创建支付、退款请求需携带请求头 `Idempotency-Key: <uuid>`，重复提交返回第一次结果（200，不重复扣款）

### 0.2 鉴权
| 端 | 方式 |
|---|---|
| C 端 | `Authorization: Bearer <accessToken>`；`POST /auth/refresh` 用 `refreshToken` 换新 |
| 运营端 | 同上；密码 BCrypt；登录返回 `roles` / `permissions` |
| 支付回调 | 微信支付平台证书验签（V3 API 验签逻辑），不校验业务 token |

### 0.3 统一响应包裹
```json
{ "code": 0, "msg": "ok", "traceId": "8f3a...", "data": { } }
```
分页 data 形如：`{ "list": [], "total": 128, "page": 1, "pageSize": 10 }`
游标 data 形如：`{ "list": [], "nextCursor": 10245 }`

### 0.4 错误码段（业务部分节选）
| code | 含义 |
|---|---|
| 0 | 成功 |
| 40000 | 参数校验失败 |
| 40100 | 未登录 / token 过期 |
| 40300 | 无权限（非本人 / 非局主 / 角色不足） |
| 40400 | 资源不存在 |
| 42900 | 触发限流 |
| 10001 | 名额已满 |
| 10002 | 报名支付超时，名额已释放 |
| 10003 | 不满足报名门槛（不返回具体门槛细节） |
| 10004 | 与已报名收费局时间段冲突（重叠 30min） |
| 10005 | 信用分不足 / 处于报名冻结期 |
| 10006 | 局状态不允许该操作（已结束/已取消/进行中） |
| 10007 | 已报名，请勿重复操作 |
| 10008 | 已在候补队列 |
| 10009 | 已取消的报名不可操作 |
| 20001 | 支付单不存在 / 已关闭 |
| 20002 | 支付渠道返回失败（可重试） |
| 20003 | 退款金额超过可退金额 |
| 30001 | 信用扣分申诉已存在 / 不在可申诉时间窗（30 天内） |
| 50000 | 系统繁忙（内部异常，含 traceId） |

## 3. 两个关键时序（供后端建模参考）

### 3.1 收费局报名
```
小程序               后端                     微信支付
  | POST /join           |
  |── Idempotency-Key──▶| ① 校验：局状态OPEN+名额+门槛+信用+时段冲突
  |                     | ② 名额扣减：UPDATE activity SET member_count+1
  |                     |    WHERE id=? AND member_count<slots AND status=2
  |                     |    （Redis Lua 预检 + DB 原子兜底）
  |                     | ③ 创建 member(待支付) + pay_order
  |◀── {payOrder, payParams} ──|
  | wx.requestPayment 拉起          |
  |  支付成功回调 ─────────────────▶| 验签+幂等(订单号) → 置成功
  |                     | ④ member 置“已确认”；发订阅消息
  | GET /payments/{orderNo} 轮询    |
```

### 3.2 取消报名 → 退款（服务端单事务 + 异步退款）
```
① 事务：member 状态→已取消，cancel_at=now
② 计算可退：refund_policy(h24=100% / h4=50% / lt4=0)
③ 应退>0 → 创建 refund(处理中) + 提交事务
④ 异步退款 Worker：调微信退款 → 成功置 refund 成功 / 失败重试(最多5次, 指数退避)
⑤ 退款成功 → 释放名额 → 通知候补第一位（15min 未支付则顺延）
⑥ credit_log：按取消时间窗记 TEMP_CANCEL(-5) 或正常退出(0)
```

## 5. 接口安全清单（上线前核对）
- 所有写操作鉴权 + 越权校验（本人/局主/运营角色），一律走服务端判定；
- 报名、支付、退款、点名携带 `Idempotency-Key` 或唯一业务号防重；
- 微信回调验签（平台证书）+ 回调地址固定 + 业务幂等；
- C 端敏感字段（手机号/紧急联系人）脱敏输出，列表接口不返回 openid；
- 全量运营操作写 `audit_log`；查询接口限流（按 token/设备/IP）。
